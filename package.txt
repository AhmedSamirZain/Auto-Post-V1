📦 المكتبات الأساسية (requirements.txt)
─────────────────────────────────────────

python-telegram-bot==20.7
  → مكتبة تيليجرام الأساسية (async، v20)
  → تثبيت: pip install python-telegram-bot==20.7

aiosqlite==0.19.0
  → قاعدة البيانات SQLite غير متزامنة
  → تثبيت: pip install aiosqlite==0.19.0

playwright==1.42.0
  → أتمتة المتصفح للنشر على فيسبوك
  → تثبيت: pip install playwright==1.42.0
  → ثم: playwright install chromium

yt-dlp>=2024.1.0
  → تحميل فيديوهات من تيك توك / يوتيوب / ريلز
  → تثبيت: pip install yt-dlp

apscheduler==3.10.4
  → جدولة الحملات بوقت محدد
  → تثبيت: pip install apscheduler==3.10.4

aiofiles==23.2.1
  → قراءة وكتابة الملفات بشكل async
  → تثبيت: pip install aiofiles==23.2.1

httpx>=0.26.0
  → مكتبة HTTP مطلوبة لـ python-telegram-bot
  → تثبيت: pip install httpx
